# Page Specification: Not Found 404 (`*`)

## 1. Purpose

Provides an elegant, accessible, on-brand error state when a visitor lands on an unknown URL or an invalid industry slug. Ensures there are zero dead ends by offering immediate, clear next steps back into the primary user journeys.

---

## 2. Page Structure & Components in Order

1. **`Seo` (`src/components/common/Seo.jsx`)**
   - Configured with `pageKey="notFound"` and `noIndex={true}` to prevent search engines from indexing error pages.
2. **`Section` (`src/components/ui/Section.jsx`)**
   - Uses `tone="tint"` to maintain visual alignment with the site's brand surfaces.
3. **`Container` (`src/components/ui/Container.jsx`)**
   - Centered content container holding:
     - Error Code Eyebrow: `404` in bold accent color (`text-accent`).
     - Main Heading: `h1` reading `notFound.title` ("Page not found" / "Page introuvable").
     - Lead Message: `notFound.message` ("The page you are looking for does not exist." / "La page que vous recherchez n'existe pas.").
4. **Action Cluster:**
   - Primary Action Button: "Home" (`nav.home` / "Accueil") linking to `/`.
   - Secondary Action Button: `CtaLink` (`intent="configure"`), which gracefully falls back to "Book a Demo" (`/demo`) when the configurator is disabled.

---

## 3. Responsive Behavior

- **Mobile (< 640px):** Centered text alignment, full-width action buttons stacked vertically with minimum 44px touch targets.
- **Desktop (>= 640px):** Inline horizontal button cluster with balanced spacing.
